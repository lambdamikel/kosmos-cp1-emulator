Sound

Port 4 = 0: silent

The second option is the wiring of the manual's melody generator (listing 40); it is switched on when that program is loaded, and off otherwise because Port 2 idles with all lines on. Instruction 23 (P4A) switches the Port 4 tone: 0 (and 255, the switch-on value) is silence, 1 is middle C, and each step up is a semitone higher.

Ports

The module above the computer has eight LEDs for Port 2 (outputs) and eight switches for Port 1 (inputs). Line 1 counts 1, line 2 counts 2, line 3 counts 4, and so on up to 128.

Ground rail and contact clips (manual section 1.53): a clip on a Port 1 terminal is a push button — hold it and that line reads 0. Clips fitted on lines:

Click a clip on the machine, or hold Shift+1…8. Switches stay put; clips spring back.

Port 2 lines 1–8 go to Port 1 lines: (0 = not wired). A program writes a number to Port 2 and reads it back, shuffled, from Port 1.

Inside

Click a line to edit that cell (5 digits: 2 for the instruction, 3 for the operand).

Keys

PC keyboard: 0–9 digits · Enter/I INP · O OUT · P PC · A ACC · R RUN · ./H STP · T STEP · Delete/X CLR · L CAL · S CAS · Esc power off/on.

Enter a program: type an address and INP (e.g. 0 0 0 INP), then five digits and INP per instruction — two for the instruction, three for the operand. Start it with the address, PC, then RUN. STP stops it, ACC shows the accumulator, an address and OUT shows a cell.
